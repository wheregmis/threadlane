A code joins one space. To have a computer help in both, join it to each. It must be on the same network as the primary to connect.
  1. Each space is its own hub. This app is paired with each one separately and merges what they report. The hubs do not know about each other, even on one computer. §2.1, §11.3
  2. Two computers to start: a Mac and a Linux machine. Either can be the primary. §2.1
  3. The primary hosts every hub and is also a machine in each space. It cannot be drained or removed from here. §3.1
  4. Which tools are installed and logged in. One gh login serves both spaces. The logins stay inside those tools; nothing here can show or copy a token. §9.3
  5. A computer in two spaces has two memberships: separate key, files, and limit. When it is off the primary's network it shows as out of reach and the primary works alone. §5.3, §5.8
  6. Usage limits belong to an account, not a machine. A task runs on whichever of Claude or Codex is available; with neither, it is blocked until a limit resets. §5.3
  7. Drain finishes current runs and takes no more. Remove stops admitting that membership's key, closes its connections, and releases its lanes. Per space. §5.3
  8. A join code belongs to one hub. After joining, the machine is identified there by its own key. §3.5, §5.3
